# Contributing to SILICON

Thank you for your interest in contributing to SILICON :wink:

You can contribute in several ways:

1. :bug: Have found a bug or have a feature request? File an [issue](./workflow.md#write-a-useful-issue)!
2. :computer: You are an experienced developer and want to contribute code? [Build](./build.md) the development version and submit a [PR](./workflow.md#step-by-step-contribution-workflow)!
3. :globe_with_meridians: Know a foreign language? Contact us and help with translation!
4. :green_apple: Have an Apple computer? Help us port Silicon to MacOs!

::: tip
**New to Git or GitHub?** Use GitHub's [open-source contribution guide](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-open-source)
and [fork-based tutorial](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project)
for an introduction. The [Git tutorial](https://git-scm.com/docs/gittutorial) and
[Everyday Git](https://git-scm.com/docs/giteveryday) are compact command-line
references. You do not need to master the advanced workflow before making a
small contribution.
:::
