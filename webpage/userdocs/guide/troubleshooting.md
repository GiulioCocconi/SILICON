# Troubleshooting

Use this page when SILICON or a circuit project does not behave as expected.

## A Circuit Output Does Not Change

Check that every input is connected to the intended component and that the final component is connected to an output. Then simplify the circuit until the smallest failing section is visible.

## A Project Opens Incorrectly

SILICON is pre-alpha, so project formats can change. If a project was created with a different build, try opening it with the same version that last saved it.

## A Component Is Missing

Some components shown in project plans are still work in progress. Check the homepage feature list for current availability before assuming a missing component is an install problem.

## The App Does Not Start

1. Confirm that the downloaded package matches your operating system.
2. Try the latest release build before a nightly build.
3. Check the GitHub issues page for platform-specific notes.
4. Report a new issue with your OS, SILICON version, and the steps that failed.

## Reporting Issues

When opening a GitHub issue, include:

- SILICON version or commit.
- Operating system and package type.
- A minimal project or exact steps to reproduce.
- What you expected to happen.
- What actually happened.
